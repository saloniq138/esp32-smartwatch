# ESP32 Smartwatch

Własny smartwatch na ESP32-S3 z BLE, sterowaniem multimediami Androida, powiadomieniami, IR i własnym UI.

## Planowane funkcje
- zegar i menu
- ekran i przyciski
- BLE z Androidem
- Play/Pause, Previous/Next, głośność
- aktualny utwór, wykonawca i okładka
- powiadomienia i wibracje
- nadajnik IR oraz uczenie pilotów
- bateria, USB-C
- custom PCB i obudowa 3D
